# Bài thực hành Buổi 1 - Thiết kế Web

## Giới thiệu
Đây là bài thực hành Buổi 1 của học phần Thiết kế Web.

Mục tiêu của bài là làm quen với môi trường phát triển Web, Git, GitHub và công cụ AI hỗ trợ lập trình.

## Công nghệ sử dụng
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub
- AI Assistant

## Cách chạy
1. Mở dự án bằng Visual Studio Code.
2. Mở file index.html.
3. Sử dụng Live Server để chạy website.
